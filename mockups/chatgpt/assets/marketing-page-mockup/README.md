# ClaimedFirst marketing page mockup

Open `index.html` to review the full responsive page. It uses the included Fraunces and DM Sans font files, so it works without loading fonts from another site.

The page is a standalone mockup. Account and discovery buttons point to the existing ClaimedFirst routes. The `desktop.png`, `mobile.png`, SVGs, and `make_mockup.py` are retained from the earlier hero-only exploration; `index.html` is the current full-page version.

The page contains no testimonials, real artist examples, platform artwork, or fabricated usage numbers. The example `#7` is labeled as illustrative.
